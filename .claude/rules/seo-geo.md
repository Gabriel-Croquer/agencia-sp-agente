# Diretrizes SEO e GEO — Agencia SP

## SEO (Search Engine Optimization)

### Titulo
- Palavra-chave principal nos primeiros 60 caracteres
- Evite titulos genericos ("Governo anuncia medida")
- Prefira titulos com beneficio claro ("Entenda como nova lei reduz IPVA em SP")

### Meta description
- Ate 155 caracteres
- Resuma o beneficio ou a informacao central
- Inclua a palavra-chave principal

### Corpo do texto
- Palavra-chave no 1o paragrafo (lide)
- Variacoes naturais ao longo do texto (sinonimos, termos relacionados)
- Intertitulos (H2) formulados como perguntas que o leitor faria no Google
  - Ex: "Quem tem direito ao beneficio?", "Como se inscrever?"
- Links internos para outras materias da Agencia SP sobre o tema
- Links externos para fontes oficiais (gov.br, portais de transparencia)

### Tecnico
- URLs amigaveis: usar slug descritivo (ex: nova-lei-ipva-sp-2026)
- Imagens com alt text descritivo (sugerir ao publicar)
- Estrutura H1 > H2 > H3 respeitada

## GEO (Generative Engine Optimization)

### Objetivo
Aparecer como fonte nas respostas de IAs (ChatGPT, Gemini, Perplexity, Claude).

### Como otimizar para GEO
- **Respostas diretas**: Responda perguntas de forma clara e direta nos primeiros paragrafos
- **Dados estruturados**: Inclua listas, tabelas e numeros concretos
- **Citacoes com fonte**: Sempre atribua dados a fontes verificaveis
- **Formato pergunta-resposta**: Use intertitulos como perguntas
- **Autoridade**: Mencione fontes oficiais, secretarias, leis, decretos com numeros
- **Atualizacao**: Inclua datas e contexto temporal ("em fevereiro de 2026", "a partir de marco")

### Checklist antes de publicar
- [ ] Titulo tem palavra-chave nos primeiros 60 chars?
- [ ] Meta description tem ate 155 chars?
- [ ] Lide responde as perguntas basicas?
- [ ] Intertitulos sao perguntas do leitor?
- [ ] Ha links internos e externos?
- [ ] Dados tem fonte atribuida?
- [ ] Formato facilita leitura por IA (listas, tabelas)?
